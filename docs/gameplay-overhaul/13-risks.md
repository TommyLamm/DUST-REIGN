# 13 風險與對策

[返回索引](README.md)

| 風險 | 影響 | 對策 |
| --- | --- | --- |
| P0 傷害入口替換（約 22 處扣血）改變既有數字 | 自檢失敗、手感改變 | 逐處比對無敵時間、`hurtFlash`、音效；P0 驗收要求行為等價並保留全部數字斷言 |
| 六個子代理同時改同一工作目錄 | 檔案互相覆寫、瀏覽器載入半成品 | 嚴格檔案所有權表；共用檔只在 P0 / P2 修改；各自連接埠；壞掉時等待而不修別人的檔 |
| 循環 import 增加（director、scoring、meta 互相呼叫） | 模組頂層讀到未初始化值 | 所有跨模組呼叫只在函式內執行；P0 骨架即建立最終 import 圖並跑自檢 |
| `Math.random` 全面換成 `rng` | 自檢替身失效 | `rng()` 未設種子時直接回傳 `Math.random()`；自檢不設種子 |
| 主武器承諾讓老玩家覺得被拿走功能 | 體驗倒退 | 四把武器開局全可選；軍械庫每幕可換；Mastery 讓承諾有回報 |
| 新敵型與首領讓彈幕過密 | 可讀性下降、手機難玩 | 敵彈池上限 260；預警時長下限；首領波生成間隔 ×1.6；手機實測為驗收項 |
| 計分尺度改變 | 舊榜不可比 | 換新榜單 ID `dust-reign-score-v2`；舊最高分以 LEGACY 顯示 |
| PUSH DEEPER 的提交時機 | 重複提交或漏交 | 一局只提交一次：撤離時選 EXTRACT 立即提交，選 PUSH DEEPER 延後到最終結束；`rt.accountRun` 在提交後清空 |
| 每日挑戰期待完全重現 | 玩家誤以為戰鬥相同 | 文案寫明「同樣的路線、突變與卡牌提供」；分流 rng 只保證這些 |
| 效能：Warden 連線、Sovereign 收縮圈、敵彈增加 | 手機掉幀 | 新渲染沿用 sprite 快取與批次；P3 量測首領戰最壞情況；必要時把 Warden 連線改為 LOW 隱藏 |
| 成就／meta 存檔損壞 | 解鎖遺失或無法開始 | 逐欄回退預設；寫入前驗證；不整份清空 |
| 平衡模擬器的機器人與真人差距大 | 門檻失準 | 模擬器只做相對比較（v0.3.0 vs v0.4.0）；評級門檻以百分位設定再由真人試玩微調，記錄在 `RELEASE.md` |
| 範圍過大 | 延期 | 分階段可回退：P0 後可停、P1 每個工作包獨立；若時間不足，優先順序 C > A > B > E > D |
