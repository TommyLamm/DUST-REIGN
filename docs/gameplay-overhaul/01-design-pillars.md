以下描述改造前的程式，用來說明這次增強要解決什麼。現行鍵位、每日種子與數值以後面各篇和原始碼為準。

| 問題 | 證據 |

| 一局沒有形狀 | 只有第 5、10 波有 Titan（`spawning.js` 的 `spawnTitan` 條件）；第 10 波後結構完全相同，沒有勝利條件。 |
| 難度只是線性堆數值 | 敵人 HP／傷害隨 `wave` 線性成長、沒有上限；生成間隔第 19 波貼地板、上限第 23 波貼 95；精英彈 14、Titan 彈 18／16 不成長。 |

| 評級與操作脫鉤 | `calculateCombatRank` 第 5 波自動 A、第 10 波自動 S，與分數幾乎無關。 |

## 設計支柱

1. **一局像一趟行軍**：三幕、三首領、一次撤離。玩家隨時知道「現在第幾幕、離首領多遠、離撤離多遠」。
2. **選擇要有重量**：開局選機體與主武器；每張卡都可能是「這局的方向」；重抽與放逐是稀缺資源。
3. **每 5 波一個新問題**：新敵型與突變按幕解鎖，讓中段不再是「同樣的怪、更多的血」。
4. **冒險換分數**：無傷、擦彈、Just Dash、合約、Heat 都是主動承擔風險換分數與資源。
5. **短局也有收穫**：每局結束都推進成就或解鎖；首次遊玩有情境提示。

## 目標一局節奏

| 時間（約） | 內容 |
| --- | --- |
| 0:00 | 開局配裝：機體、主武器、Heat（解鎖後）。 |
| 0:00–2:30 | 第 1 幕：第 1–4 波教學節奏（爬蟲、突進、蠻牛、砲兵；第 3 波首次合約、第 4 波首次突變）。 |
| 約 2:10 | 第 5 波 Titan（既有首領，保留零件與核心機制）。 |
| 幕間 | 撤離點選擇路線（下一幕的區段規則）＋軍械庫（可換主武器或強化）。 |
| 2:40–5:30 | 第 2 幕：第 6–9 波新增 Spitter、Scurrier；第 10 波新首領 Dreadnought。 |
| 幕間 | 第二次路線與軍械庫。 |
| 5:40–8:30 | 第 3 幕：第 11–14 波新增 Warden、Burrower；第 15 波最終首領 Storm Sovereign。 |
| 約 9:00 | 撤離通關：提交成績或選擇「繼續無盡」。 |
| 無盡 | 每 5 波一名強化首領輪替，Overheat 疊層持續上升，直到死亡。 |

一局通關目標 8–10 分鐘；第一次遊玩的玩家預期死在第 5–10 波（3–6 分鐘），與現況相近。
