# 03 背景地形（`src/render/terrain.js`）

[返回索引](README.md)

## 現況

每幀用不透明 `#121315` 蓋掉 CSS 背景（`.canvas-stage` 的漸層因此從未顯示），再畫 56px 網格與 38 個以上的灰三角形 / 方塊。

## 新做法：離屏快取的地表層

只在 `resize()`、DPR 改變或區段色調切換時重繪，每幀只做一次 `drawImage`：

1. **沙地基底**：雜訊貼圖疊 3 個尺度（大塊明暗、中尺度沙紋、細顆粒），以 `PALETTE.ground` 著色。
2. **沙丘紋理**：沿 35° 風向的低頻正弦帶，模擬風蝕沙脊，與風暴線方向一致。
3. **鹽原裂縫**：以 Voronoi 近似（隨機種子點 + 最近點連線）畫出龜裂紋，深色線條 + 單側高光。
4. **地物**：取代現有 `rt.terrain` 的三角形與方塊：
   - 岩塊：不規則多邊形，帶頂面高光與朝光源反方向的投影。
   - 廢鐵：鏽蝕板材、斷管、輪胎、半埋車殼（低機率大型地物），各自帶鉚釘與鏽斑。
   - 骨骸 / 支架：細線條結構，增加廢土敘事感。
5. **戰場網格**：保留戰術網格作為身分辨識，但改成極淡、只在畫面中心附近可見的「投影式」網格，邊緣淡出。
6. `rebuildTerrain()`（`src/systems/spawning.js`）維持同一個種子生成邏輯，只擴充 `kind` 種類與屬性；地物仍是純裝飾、無碰撞。

## 色調切換時的處理

區段色調切換（見 [01-art-direction.md](01-art-direction.md)）需要重繪地表。為避免換波時卡頓：

- 同時保留「目前」與「下一個」色調的兩張快取，1.5 秒過渡期間以 alpha 交叉淡入。
- 下一張快取在換波前 2 秒（`waveTime` 接近 `WAVE_LENGTH`）預先繪製。
- LOW 畫質只保留一張快取，換波時直接重繪。

## 效能

- 快取尺寸 = canvas 像素尺寸（含 DPR，上限 2）。
- 繪製一次的成本允許在 30ms 內（只發生在 resize 與換波）。

動態部分（浮塵、風暴）由 `atmosphere.js` 每幀繪製，見 [04-lighting-atmosphere.md](04-lighting-atmosphere.md)。
