# 04 光影與氛圍（`src/render/lighting.js`、`src/render/atmosphere.js`）

[返回索引](README.md)

## Lightmap（HIGH 限定，圖層 8）

- 半解析度離屏 canvas（`width/2 × height/2`）。
- 每幀：以區段環境色填滿（例如 DUSK `rgba(58,42,30,1)` 對應約 55% 亮度），再用 `'lighter'` 疊上光源貼圖，最後以 `'multiply'` 縮放貼回主畫布。
- 光源清單（每幀從 state 收集，不新增 state 欄位）：
  - 玩家：常駐 220px 薄荷色柔光 + 槍口方向的 30° 錐形手電筒光。
  - 槍口火光：開火瞬間（`player.recoil` > 0）短暫強光。
  - 子彈 / 敵彈：小半徑光點。
  - 爆炸、EMP、核心、避雷柱共振、熔岩區、Plasma 區、Titan 反應爐、Overdrive 掉落物。
- 光源數量上限 48，超過依距離玩家排序取前 48。

## MEDIUM / LOW 的替代方案

不做 lightmap，改為：動態暗角（中心亮、邊緣暗）+ 第 9 層加法光暈。視覺上接近，成本低一個量級。

## 大氣效果

- **浮塵**：固定池（HIGH 140 / MEDIUM 70），隨風向緩慢漂移，分兩層深度：小而清晰的遠景在圖層 3、大而模糊的近景在圖層 10。風暴期加速並轉為紅橙色。
- **風暴前線**（圖層 10），取代現有 7 條細線：
  - 3–4 層大面積半透明霧帶，沿 35° 捲動，降低能見度。
  - 高速沙粒條紋（保留現有方向與速度感，數量與粗細提升）。
  - 隨機遠方閃電：整個畫面極短暫的冷色閃光（Reduced Motion 關閉）。
  - 風暴開始與結束各有 0.6 秒的色調漸變。
- **色彩分級**（圖層 12）：每幀一次全畫面 `'soft-light'` 漸層填色（上暖下冷），統一畫面色溫。
- **膠片顆粒**（圖層 12，HIGH）：雜訊貼圖每幀隨機位移、alpha 0.04–0.06。
- **動態暗角**（圖層 12）：基礎強度依區段色調；生命值低於 35% 時邊緣轉紅並隨心跳（與 `stepWaveClock` 的低血量心跳音同步）脈動。

## CSS 疊層調整

- `css/hud.css` 的 `.arena-vignette` 改為較淡的靜態框邊，避免與 canvas 暗角疊加過暗。
- `.scanline` 保留，加上緩慢的掃描亮帶（Reduced Motion 下停止移動）。
