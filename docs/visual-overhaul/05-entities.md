# 05 敵人、玩家與環境物件造型

[返回索引](README.md)

## 共用規則

- **接地陰影**（`src/render/shadows.js`，圖層 4）：所有實體依固定光源方向（左上）在右下投出橢圓陰影，Titan 與 Brute 陰影更大更深。
- **三層繪製**：暗色外輪廓（1.5px，提升與地面的分離度）→ 本體分區上色（受光面 / 背光面兩色）→ 發光部件（眼睛、核心、能量線）走加法層。
- **受擊閃白**：render 在 `e.fx.lastHp` 記錄上一幀生命值，偵測到下降時設定 `e.fx.flash = 0.08`，閃白期間本體以白色覆蓋。不需改動任何 sim 的扣血程式（目前分散在 22 處）。
- **出生動畫**：首次繪製時設定 `e.fx.born = rt.renderTime`，前 0.35 秒從地面裂縫浮出（縮放 0.4→1、透明度、塵土環）。只是外觀，碰撞從生成當下就照常生效。
- **死亡動畫**：`killEnemy` 已在 sim 端產生粒子；render 端追加「殘骸碎片」（旋轉多邊形碎塊，帶慣性與地面摩擦，0.6–1.2 秒淡出）與冷卻液濺痕焦痕。死亡事件透過 `src/core/fx-events.js` 傳給 render，見 [06-combat-vfx.md](06-combat-vfx.md)。
- **移動姿態**：依移動速度做輕微前傾與步態擺動，取代現在所有敵型共用的單一 `sin` 上下擺動。
- **血條**：保留在實體上方，改為帶暗色底框與分段刻度的細條，滿血時隱藏（沿用現有規則）。

## 各敵型（`src/render/enemies.js`）

- **Crawler**：甲蟲型掃蕩機，6 條交替擺動的節肢、分節背甲、單顆琥珀感測眼；死亡時背甲裂開。
- **Rusher**：前掠式三角機體，後方雙推進器尾焰；衝刺預警時引擎由暗轉白熱、機體抖動，衝刺中留下 3 段殘影（強化現有 telegraph，預警線移到可讀性層）。
- **Brute**：重裝裝甲方塊，正面鏟板、外露活塞、肩部排氣管冒煙；受擊時裝甲板火花。
- **Artillery**：六角砲台；部署時 4 支腳架以動畫展開並在地面留下爪痕，砲管有後座與炮口煙；開火前砲口預熱由暗紅轉亮。
- **Elite**：保留八角星輪廓，加上旋轉外環與能量紋路；四種詞綴各有專屬視覺：
  - `[MRR]` 鏡面護盾：六角蜂巢力場弧面，被格擋時擊中點產生漣漪。
  - `[VTX]` 引力：周圍空間扭曲的旋轉細環，死亡黑洞改為吸積盤 + 引力透鏡暗環。
  - `[CMD]` 指揮：頭頂天線脈衝，連線到被加速的友軍（細虛線）。
  - `[BLK]` 閃爍：RGB 錯位殘影，瞬移時起訖點留下像素化殘像。
- **Titan**：
  - 本體加大細節：八角主裝甲拆成可辨識的多片裝甲板，中央反應爐有旋轉護罩，P2 狂暴時裝甲縫隙透出紅光並持續冒煙。
  - 左右磁軌重砲 / 導彈巢做成獨立的立體部件，破壞後殘骸掉落（碎片）並持續冒火花與黑煙，與現有部位破壞邏輯（`leftCannonDestroyed`、`rightPodDestroyed`）對應。
  - 出場時有 1 秒的地面陰影先行接近 + 落地衝擊環（純視覺，生成時機不變）。
- 詞綴標籤 `[MRR]` 等與 Titan 部位標籤 `[L: OFF]` 保留文字，改為帶底框的小標籤。

## 玩家機甲（`src/render/player.js`）

- 外型：雙足步行機甲俯視圖。底盤（腿部，依移動方向擺動）與上半身（砲塔，依 `p.aim` 旋轉）分離，移動時能看出「下半身走、上半身瞄」。移動方向由 render 比對前後幀位置得出，存在 `p.fx`。
- 4 種武器構型有不同砲管外型：
  - `standard`：中口徑雙管。
  - `breacher`：粗短散彈砲口 + 側邊彈藥箱。
  - `vanguard`：細長磁軌，蓄力時沿軌道亮起分段光條。
  - `arc-welder`：叉狀電極，待機時電極間有微弱電弧。
- 推進器：衝刺時背部噴射焰 + 殘影（延用 `dashTrail`）；Just Dash 時空凝滯時整個畫面短暫去飽和、只有玩家保持彩色。
- 狀態視覺：
  - Overdrive：機體外圍金色能量環 + 散熱片發紅。
  - 無敵：取代現有的整體閃爍，改為藍白色護盾外殼（Reduced Motion 下不閃爍，維持靜態外殼）。
  - 低血量（< 35%）：機身冒火花與黑煙。
- 槍口火光：依武器構型的不同形狀（星形 / 扇形 / 長條 / 電弧），走加法層 + 光源。
- 槍管後座縮進（`p.recoil * 3.5`）保留。

## 環境物件與掉落物（`src/render/world.js`）

- **不穩定核心**：外殼裂縫透光，HP 越低裂縫越多、閃爍越快，傳達「快爆了」。
- **燃油桶**：保留警示條紋，加上立體圓柱光影、桶蓋、凹痕；被踢飛時旋轉並拖曳火焰尾跡。
- **避雷柱**：增加高度感（投影較長），頂端電容球常駐微弱電弧；共振時從柱頂向外放出碎形電弧。
- **掉落物**：Scrap 改為旋轉的金屬碎片 + 薄荷色光暈；Repair 為紅色醫療艙；Overdrive 為金色能量電池；磁吸飛向玩家時拖出光尾。三種形狀必須在不靠顏色時也能分辨；高對比符號保留。
- **彈殼**：加上金屬高光，落地時彈跳一次，偶爾反光閃爍。
- **焦痕**：放射漸層 + 放射狀龜裂；敵人死亡另有依敵型顏色的冷卻液濺痕；玩家移動時留下淡淡的足跡（同樣進現有的 64 格焦痕池，`addDecal` 簽名不變）。
