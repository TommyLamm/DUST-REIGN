## 1. 極限挑戰模式核心哲學

### 1.1 從「玩家主導構築」轉為「固定題目的戰術考驗（Puzzle-Combat Trial）」
在常規 Roguelike 模式（Standard Operations）中，核心樂趣建立於**隨機升級卡挑選、流派共鳴、數值滾雪球與容錯率隨進度提升**。玩家可以透過運氣拿到神級卡片（如 `nanite-swarm`、`chain-lightning`、`kinetic-shrapnel`）直接無視怪物機制實施數值碾壓。

**極限挑戰模式（Hardcore Operations / Elite Trials）** 徹底顛覆此一邏輯：
- **預設考題，拒絕靠運氣通關**：每一道關卡為**完全確定性的戰鬥謎題**（Fixed Tactical Puzzle）。玩家的機體（Rig）、主武器（Weapon）、基礎被動數值、甚至升級樹池均被鎖定或受控。
- **純粹的手操與戰術拆解**：關卡剝離了「隨機性紅利」，所有變數轉化為**玩家的空間走位、精準度、冷卻管理、威脅優先級判定（Target Prioritization）與微操上限**。
- **統一的競技度量尺**：每一位挑戰該關卡的駕駛員，面對的是完全一致的受擊判定、彈道速度與怪物陣列，勝負與通關完全由手操實力定義。

```
【常規模式】：隨機發牌 ──> 玩家湊出強勢流派 ──> 數值碾壓怪潮（容錯率高）
【極限作戰】：固定考題 ──> 嚴苛生存與武器剋制 ──> 精準拆解機制與極限手操（容錯率 ≈ 0）
```

### 1.2 固定玩家配置的深層目的
1. **逼出每種武器的物理極限**：
   - 散彈槍（Breacher）不再只是「貼臉無腦射」，而必須在怪物反傷、酸液封路的極限縫隙中掌握「Just Dash 突進 -> 零距離轟擊 -> 瞬間後撤」的幀級節奏。
   - 電磁導軌槍（Vanguard）不再有舒適的遠程蓄力環境，必須在海量超高速亂竄散兵中，利用 EMP 聚合控場，抓住千分之一秒的「一線穿心」窗口。
   - 電弧焊槍（Arc-Welder）面對絕緣重甲與反導護盾，必須學會走位切角熔斷核心、借刀殺人的引爆鏈路。
2. **重塑微操機制的核心地位**：
   - 常規模式中被邊緣化的高階技巧：**Just Dash 無敵幀擦彈**、**Graze 邊緣擦彈過充**、**EMP 破盾破潛**、**環境油桶借爆**，在極限模式中全部成為「不練就必死」的核心生存前提。

## 2. 嚴苛限制與負面懲罰矩陣 (Handicap Constraints)

極限挑戰模式引入模組化的負面懲罰矩陣（Handicap Matrix），使駕駛員始終處於「一觸即潰」的高壓心理狀態。

| 限制維度 | 代號 | 數值機制與懲罰規則 | 設計目的與戰術影響 |
| :--- | :--- | :--- | :--- |
| **生命封頂** | `GlassHull` | **生命上限鎖定為 35 HP**（Strider）或 **50 HP**（Bulwark / Scrapper）。無任何途徑提升 HP 上限。 | 任何常規攻擊命中 2 次即宣判死亡；首領重擊直接秒殺。徹底根除「血量硬吃換血」戰術。 |
| **致殘衝擊** | `Rupture` | **單次受擊固定扣除約 32% 最大生命值**，且受擊無敵幀約 **0.4s**（仍短於一般戰役，但避免 0.08s 多段瞬殺）。 | 保留硬核壓力，但給出可讀的受擊節奏；連續碰撞不再必然雙擊秒殺。 |
| **補給飢荒** | `ScrapFamine` | **廢料修復機率降低 75%**；拾取修復廢料僅恢復 6 HP（常規為 18 HP）；滿血時拾取廢料僅折算分數，**不提供任何臨時護盾**。 | 失去自動回血容錯。每一滴血都是不可逆的珍貴資源，迫使玩家把走位當作唯一防禦。 |
| **物資誘餌** | `BaitCrates` | 補給箱刷新間隔延長 150%；補給箱開啟需要停留在箱體周圍 **1.2s 解碼**，同時引發半徑 200px 的警報引來 4 隻高威脅獵殺者。 | 貪婪與風險的極致博弈，不能在混亂戰場中無腦衝過去撞箱。 |
| **時空風暴** | `FlashStorm` | **風暴倒計時壓縮至 15s**（常規 35s+）；波末風暴風速提升 60%，推力達 95px/s；風暴中敵軍移動速度 **+25%**，射速 **+30%**。 | 徹底剝奪玩家繞圈打消極消耗戰的時間空間，逼迫在風暴降臨前以極高效率清理怪潮。 |
| **強風偏轉** | `WindShear` | 戰場伴隨狂風，玩家射擊彈道產生 **12°~18° 橫向偏轉漂移**，逆風移動速度 -20%。 | 考驗瞄準補償與滑步射擊（Strafing）技巧，站立射擊會被風壓快速推向地圖邊緣危險區。 |
| **過載反噬** | `Burnout` | Just Dash 冷卻時間從 1.4s 延長至 **2.0s**；若未成功觸發 Just Dash（普通空翻）將產生 0.25s 輪機停滯（移動速度 -40%）。 | 杜絕亂按 Dash 盲目躲避，只獎勵看清彈幕前搖後的「極限壓幀擦彈」。 |

## 3. 針對玩家武器特性的「剋制型怪物陣容」矩陣 (Weapon-Counter Matrix)

極限模式最核心的戰術靈魂，在於**精確拿捏玩家手持武器的致命短板，並派出量身定製的剋制型天敵組合**。

```
┌─────────────────────────────────────────────────────────────┐
│                   WEAPON-COUNTER TRIANGLE                   │
│                                                             │
│   BREACHER (近戰散彈)       ──>  怕：遠程砲擊洗地、地面酸液、貼臉自爆蟲   │
│   VANGUARD (穿透導軌)       ──>  怕：高速散開小蟲、鏡面反彈、閃爍突襲     │
│   ARC-WELDER (連鎖電弧)     ──>  怕：絕緣重甲巨獸、光盾發生器、死亡火海   │
│   STANDARD (通用步槍)       ──>  怕：重裝盾牆陣列、群體加速光環、超群怪海 │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 剋制 Breacher（散彈槍／近戰高爆發）
- **武器特性分析**：散彈槍具備毀滅性的近距離點爆發（5~7 發彈丸全中），自帶強大後座力與擊退，但**射程短、彈丸擴散劇烈、遠程衰減高達 70%、開火間隔有明顯節奏停頓**。
- **天敵剋制陣容設計**：
  1. **遠程砲兵連隊（Triple Artillery Phalanx）**：
     - 開局在戰場四個對角交叉架設，不主動接近玩家，而是向玩家站位進行高密度的覆蓋式迫擊砲輪射。
     - 迫擊砲落地後殘留 **直徑 80px 的高溫熔渣區**（持續 4.5s），大面積封鎖中遠程走位。Breacher 玩家根本無法安全接近。
  2. **強酸封路者（Spitter Acid Network）**：
     - Spitter 不瞄準玩家本體，而是封鎖玩家朝向砲兵前進的衝鋒路徑。綠色強酸池使玩家移速降低 45%，踩踏時每 0.2s 受到腐蝕傷害。
  3. **貼身自爆幼體（Volatile Scurrier / Kamikaze Swarm）**：
     - 超高速（速度 160+）的 Scurrier 密集貼身。若玩家用散彈近距離轟殺，死亡瞬間立刻觸發半徑 70px 的破片爆炸（傷害 30 HP）。**若近身開槍，等同於玩家把自己炸死！**
- **解題操作考驗（The Puzzle Solution）**：
  - **引擎原生機制破局**：在 DUST//REIGN 底層代碼中，`new-enemies.js` 明確判定 `if (ev.cause === 'dash') return;` —— **利用 Dash 衝撞擊殺 Scurrier 絕不觸發自爆！**
  - 玩家必須利用 Breacher 的後座力微調位移，主動使用 Just Dash 衝入蟲群撞死自爆蟲引導破口，再利用無敵幀貼近 Artillery，在 0.5s 內完成「貼臉兩管全彈轟爆 -> 側向滑步後撤」的極限刺殺。

---

### 3.2 剋制 Vanguard（電磁導軌槍／慢射速直線穿透）
- **武器特性分析**：慢速蓄力（0.6s / 0.45s）、超長射程、直線無限穿透，對直線排隊的密集敵人是死神；但**彈道極窄、蓄力時機動受限、對全方位分散的高速個體處理極慢、空槍時間成本極高**。
- **天敵剋制陣容設計**：
  1. **鏡面反射精英（Mirror Elite Bulwark）**：
     - 配備鏡面離子護盾。導軌槍直射擊中反射盾時，彈體不會穿透，而是**以 100% 原始殺傷力沿入射角反彈**！在密閉戰場中，反彈的導軌射線極容易直接秒殺玩家自己。
  2. **高頻散開型掠食者（Scattered Scurriers & Rushers）**：
     - 從玩家的 360° 全方位以散開扇形逼近，絕不走成直線。導軌槍一槍只能殺死一隻，其餘方向的掠食者會在玩家 0.6s 蓄力冷卻期間飛撲近身撕裂機體。
  3. **閃爍暗殺者（Blink Stalker）**：
     - 具備感知蓄力的行為樹。當偵測到玩家 Vanguard 蓄力進度達到 75% 時，立即瞬間傳送（Blink）至玩家後背盲區發動突襲，打斷蓄力並造成背擊重傷。
- **解題操作考驗（The Puzzle Solution）**：
  - **EMP 戰術聚怪**：禁止直瞄開槍。必須把 EMP 衝擊波作為前置控制技，在釋放 EMP 癱瘓 Mirror 精英盾面的瞬間，將散開的蟲群定身拉出直線通道，隨後一發蓄力貫通核心。
  - **幾何跳彈與環境借力**：利用戰場上的炸藥桶（Lethal Barrels），射擊炸藥桶引發 360° 物理爆震來清理四周分散的小蟲，主武器射線專門留給解盾後的精英。

---

### 3.3 剋制 Arc-Welder（電弧焊槍／持續引導連鎖閃電）
- **武器特性分析**：持續光束引導鎖定、多目標自動跳躍連鎖（Chain ratio 0.7）、疊加熔化持續傷害；但**射程中等（110px 連鎖半徑）、需持續面向目標引導（持續佔用開火操作）、缺乏爆發擊退力、被硬光屏障完全阻斷**。
- **天敵剋制陣容設計**：
  1. **重型絕緣裝甲巨獸（Insulated Brute Titan）**：
     - 外殼塗覆厚重絕緣陶瓷層，**完全免疫電弧連鎖帶來的麻痺與減速**，且受到的電弧傷害降低 65%。頂著高壓電流以堅定不移的步伐直接將玩家逼向角落。
  2. **懸浮護盾發生器（Warden Phalanx）**：
     - 2~3 架 Warden 浮空機在後排架起硬光防禦網，為前方怪潮提供 200 HP 護盾。電弧打在護盾上只會被光盾無效化吸收，**電弧連鎖無法越過護盾跳躍至後方本體**。
  3. **殉爆與酸液留痕（Volatile Acid Cluster）**：
     - 連鎖電弧往往會無差別電死周圍的 Volatile 詞綴怪物。這些怪死後在周圍化作大片火海與爆炸區，導致正在持續引導光束的玩家若不及時中斷射擊撤離，便會被連鎖反應的烈焰吞噬。
- **解題操作考驗（The Puzzle Solution）**：
  - **繞後切角熔斷核心**：不得正面硬電護盾前排。玩家必須利用 Strider 或 Scrapper 的側移衝刺，甩出圓弧形走位繞過絕緣 Brute，將光束死死咬住後排的 Warden 發生器，在光盾崩潰的瞬間引發超載。
  - **借爆破甲戰術**：故意引導電弧點燃邊緣的 Volatile 怪物，利用其爆炸產生的 60 點範圍真實傷害，直接炸碎絕緣 Brute 的重裝護甲。

### 3.4 剋制 Standard Rifle（雙聯裝通用突擊步槍）
- **武器特性分析**：平衡性極佳的點射武器，中遠程均有穩定 DPS，但**缺乏範圍清場 AOE、單發穿透力低、面對 50+ 超飽和怪潮時清理效率存在物理上限**。
- **天敵剋制陣容設計**：
  1. **超密集重裝盾海（Shield Swarm Wall）**：
     - 前排由 20+ 隻重裝護盾 Crawler 與 Brute 組成嚴絲合縫的推進盾牆，完全抵擋雙聯步槍的正面彈道。
  2. **光環指揮官（Command + Vortex Elite Commander）**：
     - 帶有雙重詞綴的精英指揮官。`command` 使全場怪潮移動速度 +40%、抗擊退提升 80%；`vortex` 週期性在玩家腳下生成微型黑洞，將玩家向盾牆中心拉扯。
  3. **同屏超飽和壓境（65+ Active Entities）**：
     - 怪物同屏數量拉升至極限（65 隻），生成間隔壓至 0.22s。普通點射步槍在彈幕散布擴大時，根本無法阻止四面八方合圍的狂暴洪流。
- **解題操作考驗（The Puzzle Solution）**：
  - **嚴格控槍節奏**：禁止持續按死扳機（避免散布擴大），採用高節奏的「3連發點射」觸發 Tracer 標記，優先點殺後排的 Command 指揮官解除怪潮全體 Buff。
  - **誘敵漏斗走位（Funnel Kiting）**：在邊界打出「8 字形」拉扯航線，將 65 隻怪潮拉成一條長蛇陣，利用 Just Dash 釋放的動能衝擊波削弱群體血量，再逐段點名撕裂。

## 4. 同屏怪潮與波次動態縮放 (Swarm Scaling & Elite Saturation)

極限作戰模式採用了一套專屬的動態波次配方（Trial Wave Recipe），數值曲線大幅超越常規 Act 1~3 的溫和遞增。

### 4.1 核心戰場數值對比表

| 數值參數 | 常規模式 (Standard Waves 1~15) | 極限作戰模式 (Hardcore Operations) | 數值意義與實戰體感 |
| :--- | :--- | :--- | :--- |
| **同屏實體上限 (Cap)** | 9 隻 (W1) ~ 36 隻 (W10) ~ 45 隻 (W15) | **固定 55 ~ 70 隻**（依關卡難度鎖定） | 戰場幾乎無任何死角留白，視覺壓迫感拉滿，空間資源極端緊繃。 |
| **生成間隔 (Spawn Interval)** | 1.08s (W1) ~ 0.45s (W10) ~ 0.32s (W15) | **0.20s ~ 0.28s** | 擊殺一隻怪物的 0.2 秒內立刻有新怪補位，絕無喘息窗口。 |
| **精英怪基礎概率 (Elite Chance)**| 0% (W1) ~ 8% (W5) ~ 16% (W15) | **開局即 25% ~ 40%** | 場上隨時保持 3~5 隻精英怪帶光環同時壓境。 |
| **詞綴解鎖波次 (Affix Unlock)** | W4 解鎖基礎 / W8 炸裂 / W13 分裂 / W16 雙綴 | **Wave 1 全面解鎖，且 100% 機率攜帶雙重詞綴** | 怪物組合威脅倍增（如 Mirror + Blink，或 Volatile + Splitter）。 |
| **敵軍移速加成 (Speed Mult)** | 1.0x (基準) | **1.25x ~ 1.40x** | 怪物包圍圈收縮速度極快，考驗第一反應手速。 |
| **敵方攻擊前搖 (Telegraph Window)**| 0.8s ~ 1.2s | **0.4s ~ 0.6s** | 迫擊砲紅圈與狙擊紅線提示時間減半，只留出剛好夠反應的極限時間。 |

### 4.2 致命雙重詞綴（Dual-Affix Elite Combinations）配對庫

在極限作戰中，所有精英敵人都將從以下高難度複合詞綴池中隨機或固定生成：

1. **【閃爍鏡面】`mirror` + `blink`**：
   - 具有子彈反射盾，且每 3 秒瞬間傳送至玩家側翼。如果玩家正在開火，極容易在它瞬移到槍口前的一瞬間誤射反射盾，導致自己秒殺自己。
2. **【殉爆裂殖】`volatile` + `splitter`**：
   - 擊殺後先在原地引發半徑 110px 的 30 傷害巨型烈焰爆炸，隨後立刻分裂出 3 隻高速狂暴幼體！清理這類精英必須留足安全距離。
3. **【引力霸權】`command` + `vortex`**：
   - 周圍小怪獲得 40% 移速與免疫擊退加成，同時自身釋放引力黑洞將玩家強制拖向周圍的狂暴怪海中。優先級第一的滅霸級目標。

### 典範關卡 01：代號【鋼鐵斷頭台】(Operation Steel Guillotine)

## 6. 架構對齊與系統實作接口 (Architecture & Code Contracts)

為確保本模式能無縫整合進 DUST//REIGN 現有代碼體系，以下規劃了模組責任與擴展路徑，所有契約完全符合 `ARCHITECTURE.md`：

### 6.1 資料層擴展：`src/data/trials.js`（新建）
定義極限挑戰關卡的固定靜態資料契約：
```javascript
export var HARDCORE_OPERATIONS = [
  {
    id: 'steel-guillotine',
    title: 'OPERATION STEEL GUILLOTINE',
    rigId: 'strider',
    weaponId: 'breacher',
    maxHpOverride: 35,
    fixedDmgPercent: null,
    scrapHealMult: 0.25,
    screenCap: 55,
    spawnIntervalMult: 0.65,
    eliteChanceMult: 2.5,
    stormClockOverride: 15,
    fixedBoss: 'titan-anvil',
    counterWeights: { crawler: 0.15, rusher: 0.15, brute: 0.10, artillery: 0.30, spitter: 0.20, scurrier: 0.10 },
    affixPoolOverride: ['volatile'],
    honorTitle: 'The Razor\'s Edge',
    badgeId: 'badge-steel-guillotine'
  },
  // ... 其餘 5 大關卡資料表
];
```

### 6.2 流程與生命週期掛載
1. **開局套用（`src/systems/flow.js` -> `beginRun()`）**：
   - 檢查單局是否包含 `rt.state.trialId`。
   - 若為 Trial 局，調用 `applyRig(player, trial.rigId)` 後，強制覆寫 `player.maxHp = trial.maxHpOverride; player.hp = trial.maxHpOverride;`。
   - 強制鎖定 `rt.state.weaponId = trial.weaponId;`，並禁用幕間更換武器面板。
2. **傷害與受擊過濾（`src/systems/combat.js` -> `damagePlayer()`）**：
   - 若存在 `trial.fixedDmgPercent`，單次受擊傷害計算改為：
     ```javascript
     if (rt.state.trial && rt.state.trial.fixedDmgPercent) {
       amount = Math.ceil(p.maxHp * rt.state.trial.fixedDmgPercent);
     }
     ```
3. **波次導演接管（`src/systems/director.js` -> `planWave()`）**：
   - 在計算 `recipe` 時，若處於極限挑戰模式，直接將 `recipe.cap` 覆寫為 `trial.screenCap`（55~70），`recipe.interval` 乘上 `trial.spawnIntervalMult`，並注入專屬剋制權重 `trial.counterWeights`。
4. **存檔與榮譽結算（`src/core/meta-store.js`）**：
   - 在本地持久化存檔中新增 `dust_reign_trials_cleared` 鍵值，記錄各 Operation 的通關狀態、用時與獲得的徽章。
